# mgravey.com

Personal research website for Mathieu Gravey. The site is generated by Jekyll,
uses Barba.js for progressive internal-page transitions, and is deployed only
to GitHub Pages from the `jeykill-version` branch.

## Authoritative content

Reusable information is maintained once:

- `_data/person.yml` — profile, focus areas, links, contact values, and CV references.
- `_data/cv.yml` — experience, education, awards, skills, and languages.
- `_data/portfolio.yml` — projects and software; `types` controls where each record appears.
- `_data/publications.yml` — DOI, citation metadata, flags, and ordering.
- `_data/taxonomy.yml` — tag labels, groups, filter visibility, and logos.
- Page front matter — each page’s title, permalink, description, background, and navigation order.
- `_data/nav.yml` — external navigation entries only. Viewpoints intentionally remains a separate site.

Page-specific essays and guidance stay in their Markdown pages. Do not copy
profile, CV, publication, project, or software facts into page prose.
All destinations are shown directly in the desktop navigation bar; the same
ordered list becomes a flat drawer on narrower screens.

## Local development

Use Ruby 3.2, Bundler 2.5.23, and Node.js 22.

```sh
bundle install
npm ci
npm run serve
```

`npm run serve` creates the optimized images and JavaScript bundle before
starting Jekyll. Generated files under `assets/generated` and `assets/dist` are
not committed.

Create a production build with:

```sh
npm run build
```

## Updating content

Add or edit projects and software in `_data/portfolio.yml`. A record can appear
on both pages by using:

```yaml
types: [project, software]
```

To add a publication and retrieve its Crossref metadata:

```sh
npm run publications -- 10.xxxx/example
```

Review the updated `_data/publications.yml`, add any local flags or rank, run
`npm run validate`, and commit the resulting single catalog.

Original photographs live under `assets/source-images`. The asset task produces
WebP copies below the enforced transfer-size limits.

## Tests

```sh
npm test
```

This validates the data model, builds Jekyll with strict front matter, checks
the generated HTML, and runs Playwright smoke tests for direct navigation,
Barba transitions, filters, dialogs, mobile navigation, reduced motion, and
JavaScript-free fallback.

## Deployment

`.github/workflows/pages.yml` validates pull requests targeting
`jeykill-version`. Pushes to that branch run the same checks and deploy the
generated `_site` artifact to GitHub Pages. The canonical domain is
`https://www.mgravey.com`.

Viewpoints is deployed independently at `/viewpoints/`; its links deliberately
bypass Barba with `data-barba-prevent="all"`.
